# Photos

Drop your real photos here using these exact filenames (.jpg, .png, or .webp all work — the
site tries `.jpg` first and falls back to an elegant placeholder automatically if a file is
missing, so nothing ever looks broken).

| Filename | Used in |
|---|---|
| `hero-couple.jpg` | Full-screen hero photo (Ken Burns zoom) |
| `love-story-1.jpg` … `love-story-4.jpg` | Love Story horizontal gallery |
| `gallery-1.jpg` … `gallery-8.jpg` | Pinterest masonry + infinite strip |
| `bw-1.jpg` … `bw-4.jpg` | Black & white film-grain section |
| `venue.jpg` | Venue section photo |
| `final-portrait.jpg` | Final "You Are Invited" full-screen portrait |

Tips:
- Use portrait/vertical crops for `love-story-*` and tall `gallery-*` images for the best masonry look.
- Keep files under ~500KB each (export at ~1600px on the long edge) for fast mobile loading on WhatsApp.
- If a filename doesn't match exactly, the placeholder gracefully stays in its place.
